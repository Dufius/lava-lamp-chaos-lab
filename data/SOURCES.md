# Dataset Sources & Attribution

## Real lava lamp footage (`data/raw/`, `data/frames/`)

Seven lava lamp video clips downloaded from Wikimedia Commons:

- **Files:** `Lava lamp (oT) 01–07 ies.ogv`
- **Author:** Frank Vincentz
- **License:** [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- **Source:** https://commons.wikimedia.org/wiki/Category:Lava_lamps
- **Specs:** 1270×720, 25 fps, ~28 min total (~41,000 frames)

Because this footage is CC BY-SA 3.0, any redistribution of the clips or
of frames/models derived from them must credit "Frank Vincentz" and remain
under a compatible share-alike license.

### Reproducing the frame dataset

The raw `.ogv` clips and extracted frames are not committed (they're large
binaries — see `.gitignore`). To regenerate:

```bash
# 1. Download the clips into data/raw/ (see download command in git history)
# 2. Extract frames:
python scripts/extract_real_dataset.py
```

This samples every 12th source frame (~0.5 s apart at 25 fps, so consecutive
samples show meaningful blob motion), resizes to 256×256, and writes ~3,400
JPEGs to `data/frames/` prefixed by clip id (`lampNN_######.jpg`). The clip
prefix keeps each clip's frames contiguous in sorted order, so the dataset
loader only ever forms a handful of cross-clip training pairs.

### Training on the real dataset

```bash
python -m src.train --data-path data/frames --model unet \
  --epochs 30 --batch-size 32 --device cuda
```

## Synthetic test data (`data/samples/`)

Generated by `scripts/generate_test_data.py` — moving Gaussian blobs, used
for smoke-testing the pipeline without any download. Not physically
realistic; use the real footage above for actual experiments.
